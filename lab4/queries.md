# CRUD операции MongoDB

Основной файл с запросами:

```text
queries.js
```

Запуск:

```bash
mongosh "mongodb://localhost:27017/hotel_booking_docs" queries.js
```

## Что сделано

Файл содержит операции:

- `Create`: `insertOne` для `bookings`, `reviews`, `user_preferences`, `booking_events`;
- `Read`: поиск бронирований, отзывов, предпочтений и событий;
- `Update`: обновление статуса брони, оплаты, модерации отзыва, предпочтений пользователя;
- `Delete`: удаление служебных событий, старых отзывов, временных предпочтений;
- soft delete для бронирований через смену статуса на `cancelled`.

## Использованные операторы

В запросах используются:

```text
$eq
$ne
$gt
$lt
$in
$and
$or
$set
$inc
$push
$pull
$addToSet
```

## Почему бронирования удаляются через soft delete

Для бронирований физическое удаление обычно нежелательно: они нужны для истории пользователя, финансовой аналитики и аудита. Поэтому удаление бронирования реализовано как обновление статуса:

```javascript
{
  $set: {
    status: "cancelled"
  }
}
```

Физическое удаление используется только для технических или временных данных.
