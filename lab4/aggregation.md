# Агрегации MongoDB

Файл:

```text
aggregation.js
```

Запуск:

```bash
mongosh "mongodb://localhost:27017/hotel_booking_docs" aggregation.js
```

## Основной pipeline: отчёт по выручке отелей

Первый aggregation pipeline строит отчёт по бронированиям отелей за период.

Используются стадии:

```text
$match
$group
$project
$sort
```

## Что делает запрос

Pipeline:

1. Отбирает активные и завершённые бронирования за период.
2. Группирует документы по отелю.
3. Считает:
   - количество бронирований;
   - общую выручку;
   - средний чек;
   - количество ночей;
   - количество гостей;
   - набор статусов бронирований.
4. Добавляет вычисляемое поле `revenuePerNight`.
5. Сортирует отели по выручке.

## Дополнительные pipeline

В файле также есть ещё два примера:

1. Статистика бронирований по месяцам и статусам.
2. Отчёт по средним оценкам отелей на основе коллекции `reviews`.

## Почему это сложный запрос

Обычный `find` подходит для получения отдельных документов, но не подходит для аналитики. Для отчёта по выручке нужно:

- отфильтровать документы;
- сгруппировать их по отелю;
- вычислить агрегаты;
- преобразовать структуру результата;
- отсортировать итог.

Это типичный сценарий для MongoDB Aggregation Framework.
